# TexoPub.ai 品牌视觉提案 v0.2

2026-10-22。用户已选定名称 **TexoPub.ai**，要求更新 logo 和配色供查看。本目录是本地视觉提案，尚未替换正式网站模板或部署，未购买或绑定域名。

## 设计背景

定位仍是 AI 作品门户：发现、使用和发布人与 AI 共创的网页与作品。用户确认的气质为亲切、清楚、有活力。此前用户关于 AI 友好的讨论，最终澄清为在名称后添加后缀；不把它解释成另一个未经确认的平台战略。

## 标志与字标

- 用新的 **交织的 T** 替代早期 AI123 的 A 门洞。T 取自 Texo，左右横带在中央留白，竖带穿过，呼应编织。编织是视觉意图，不代表已验证的用户联想或商标独特性。
- 主字标统一写作 **TexoPub.ai**，TexoPub 使用墨色，右上角 .ai 使用朱橙。保留名字主体的可读性，AI 作为清楚的小标识。
- 同行版让 .ai 与名称同一基线，适用于完整网址、窄高度页头及小字号文字应用。
- 深色版使用暖白文字、浅橙标志与 .ai；单色版全部墨色。
- 主字标建议宽度至少 180px；小尺寸以 T 为主。四周安全空间建议至少为符号宽度的四分之一。
- 未覆盖或替换任何单独作品的图标。

## 配色

| 角色 | 色值 | 使用 |
| --- | --- | --- |
| 朱橙 | #C74727 | 品牌、主要行动、选中态 |
| 暖白 | #FAF8F3 | 页面主背景 |
| 墨色 | #222B28 | 标题、正文与字标 |
| 浅砂 | #F0ECE4 | 轻量分区与搜索区域 |
| 辅助绿 | #1E6B52 | 分类链接、成功状态 |
| 次要文字 | #69736C | 说明与元信息 |
| 深色用浅橙 | #FFAD8F | 在墨色背景上使用的标志与 .ai |

大面积背景与文字以暖白和墨色为主，朱橙聚焦品牌及关键行动；辅助绿少量使用。沿用上一版的核心配色，不引入额外主色。

## 字体与源文件

字标沿用 Manrope，选择 800 字重并做少量光学字距调整。Google Fonts 原始可变字体与 OFL 授权位于 `fonts/`。所有交付 logo SVG 均转换成路径，不依赖观看环境安装字体。中文网页使用 Noto Sans SC；网络字体不可用时回退系统中文字体。展示图的中文为普通 SVG 文本，PNG 为独立可查看结果。

字体来源：https://github.com/google/fonts/tree/main/ofl/manrope 。

生成源为 `build_brand.py`，使用项目内 `.tools/brand-venv` 的 fonttools。PNG 由现有工作区运行时的 sharp 渲染。重新生成：

```sh
.tools/brand-venv/bin/python design/texopub/build_brand.py
```

## 文件

- `index.html`：互动品牌板，提供四种字标切换、色值复制、首页局部应用、真实作品搜索与资源下载。
- `logo.svg`、`logo-inline.svg`、`logo-reverse.svg`、`logo-mono.svg`：四种路径化字标。
- `mark.svg`、`mark-mono.svg`、`app-icon.svg`：符号及头像应用。
- `preview.svg` / `preview.png`：完整品牌展示图。
- `logo.png`：透明背景字标；`mark-16/32/64.png`：实际像素图标；`app-icon-180/512.png`：头像/应用尺寸。
- `tokens.css`：配色变量；`work-icon.svg`：仅供局部页面示意的原苏博图标副本。

此前 AI123 提案仍保存在 `design/ai123/`，作为历史方案。下一步依据用户的视觉反馈收敛；应用到线上网站及域名购买另按明确范围执行。
