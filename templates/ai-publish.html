凭证和 Skill 有什么区别？

Skill 是公开的使用说明和客户端；凭证是你在个人空间创建的密钥。AI 安装 Skill 后，仍需读取你下载的个人凭证文件才能发布。查看登录、创建和使用步骤 →

要自己选文件、手动上传吗？

这里的发布入口只提供给 AI 的提示词。把你要公开的网页或素材交给自己的 AI，由它调用发布服务；网站不提供文件选择或拖拽上传。

发布完成后，去哪里查看？

托管发布后，AI 会自动拿到 content.texopub.com 下的短网址，作品也会加入首页分类导航。同名作品自动加短后缀，更新时网址保持不变。独立图片、音视频和文档默认进入自己的私有素材库；明确公开后才可供他人访问。更新作品时保留网址。

已经有自己的网站和域名，也能加入吗？

可以。选择「收录已有网站」，把网址交给你的 AI。使用自己的发布密钥提交简介、分类和专属图标，作品就会加入目录；点击后直接访问原站，内容仍由你自行托管。此功能不涉及域名绑定或网站迁移。

我的 AI 能安装这个 Skill 吗？

需要能读文件并执行 Python 或调用 HTTP 接口的 Agent。如果它不支持安装 Skill，也可以读取在线技能说明，使用随包客户端完成相同流程。

哪些内容适合分享？

有用的指南、研究、教程、可视化与交互工具都欢迎。只发布你明确同意公开的内容，并保留来源说明；分享许可由作者决定。第一版有文件大小和静态网页能力限制，AI 会按 Skill 中的说明检查。
