# TexoPub A 方向整站预览

2026-10-26。本地交互版本，位于 `feat/community-gallery` 分支。用户选择先看完整预览，再决定合并上线。

## 运行

在项目根目录执行：

```sh
python3 next/scripts/build.py
python3 next/scripts/preview.py
```

访问 `http://127.0.0.1:8770/`。`/preview.html` 可切换页面和桌面、390px、320px 宽度；这只是浏览器尺寸预览，不代表手机真机验收。服务仅监听本机回环地址。

## 页面与行为

| 地址 | 内容 |
| --- | --- |
| `/` | 搜索、封面画廊、快捷分类、全部分类、空结果恢复 |
| `/u/preview/` | 人类创作者身份、紧凑 AI 伙伴、共创作品 |
| `/space/` | 个人空间概览 |
| `/space/works/` | 作品展示与底部 AI 更新说明 |
| `/space/materials/` | 本地演示素材与底部 AI 整理说明 |
| `/space/settings/` | 资料、伙伴、默认范围、本人授权入口 |
| `/space/settings/keys/` | AI 连接与正式授权管理入口 |
| `/publish/` | 静态发布步骤；插件与本地 Agent 两条接入路径 |
| `/login/` | 登录视觉与进入演示工作区；不发送验证码 |
| `/materials/` | 公开素材快照、搜索和继续加载 |
| `/about/` | 定位、命名来源与预览说明 |

全部分类从项目 `taxonomy.json` 读取，8 大类、28 子类。筛选有 36 个父/子选项。人类与 AI 分别采用人物轮廓和芯片图标；SVG 统一 24px 网格与 1.7 线宽。浏览控件提供键盘焦点、名称与状态。

AI 提示是内容底部、页脚之前的一块说明区域，一页一句，只提当前页可由 AI 发布或更新的内容，不重复平台总说明。发现、本人主页、概览、作品、素材和设置各有不同文案；只读、登录、授权等无对应编辑任务的页面不放无关提示。没有页头 AI 操作入口、卡片管理/复制按钮、重复素材查看链接或任务弹窗。发布指南改为静态步骤与接入链接；本人登录、授权操作保持。整体检查见 `整站精简检查.md`。

## 资料来源与默认策略

- `data/catalog.json` 仅包含本轮读取到的三份公开作品，不含“不展示”的作品。`data/materials.json` 为公开接口的 141 份素材快照，不能当作实时目录。
- `data/suzhou-cover.jpg` 是项目已有公开苏博原图的字节相同副本，便于本地预览；没有修改原图。其余封面由标题、分类、图标与作品 ID 配色排版；封面加载失败也回退到排版封面，无需生图。
- `data/identity-lexicon.json` 是 Codex 按用户要求为 TexoPub 原创起草的项目词表，未抓取词典、人名库或用户资料。首版 24 个前缀与 16 个后缀，384 个不同组合，供产品审核。昵称允许重名，账号标识唯一；明确指定名字优先。正式接入时首次生成后保存，词表升级不重命名既有用户。
- 预览中旧占位署名按账号 ID 确定性生成名字和几何头像；没有修改真实账号。AI 伙伴示例为 Codex，默认可用已知应用名，明确昵称优先，头像按伙伴 ID 生成。没有虚构具体模型、简介或贡献记录。
- 工作区采用演示身份和一份本地 SVG 素材，不读取私有素材或登录凭证。AI 署名是展示示例，不宣称三份旧作品均已完成真实伙伴登记。
