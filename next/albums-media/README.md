## 可实际体验的范围

- 一个混排网页、视频与音频的独立分享专辑，有专属1600×900封面、标题、创作者、更新时间、内容目录、搜索、类型筛选和无结果恢复。
- 本人概览、专辑、作品、素材、设置，个人主页及其专辑区域、全部专辑页，发现、公开素材和AI接入说明；素材可搜索和按类型筛选。
- 默认专辑和标注网页均为 unlisted，公开主页上没有该专辑或标注页。隔离测试专辑仅主页展示时，区域位于作者信息下、共创作品上；不会改变成员 listing 或主页授权开关。
- 真实网页在 sandbox iframe 中运行，能够放大原帧、前后帧对照、切换两个视频、筛选候选声音和循环播放节点。没有冒称这份试标已经逐条听审或通过准确率检验。
- 两段12秒视频真实播放、进度拖动、倍速、音量/全屏等原生控制；第二段跨源读取。WAV音频从同一预览视频解码为PCM，保留原视频、原音轨和源HTML。
- 媒体带专辑上下文时可返回专辑/切换同专辑内容；独立资源地址不反向披露 unlisted 专辑。视频不自动播放，平台模式打开第二本机源的可播放原站模拟页。
- 管理结果通过验收面板进行本地状态模拟：排序、重复加入去重、移出/恢复、归档成员、删除专辑保留内容、过期修订拒绝、封面替换及缺失/读取失败兜底、分享卡片、空/加载/错误/重试、访客视角及主页开关。
- 可开启第二个隐藏的「试标复核（预览样例）」专辑，实际进入并引用同一标注网页。删除第一个专辑不影响另一个或原作品，不复制资源。此样例默认关闭，亦不进入个人主页。
- 大文件上传演示明确标记为模拟：180MiB虚拟文件/12分块，观察进度、中断、保留分块、刷新、断点继续、校验/提交。没有真实文件传输、服务端存储或额度变更。
- 用户封面校验示例覆盖尺寸、格式、大小和其他比例的裁剪提醒。生成的专属SVG封面与用户提供JPG/PNG/WebP的格式要求分别处理。

内容仍通过AI管理。产品页面没有手工上传/内容编辑/复制按钮；验收面板的控件不属于正式产品交互，页面和同源本地状态通过storage事件联动。测试操作只存浏览器本地 `texopub-albums-preview-20261102-v1`，点击面板底部“恢复约定”即可重置。独立浏览器的预览状态互不相通。
