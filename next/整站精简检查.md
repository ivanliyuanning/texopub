# 整站精简检查 · 2026-10-26

范围：`feat/community-gallery` 本地预览，11 个产品页面及异常路由。未改生产服务、账号、作品或授权。

## 页面提示

只在有对应发布或资料更新需求的页面保留一块底部说明。每页一句，文案不重复“本站不提供手动编辑”的总说明。

| 页面 | 提示内容 |
| --- | --- |
| 发现 | 把网页或网站地址交给 AI，发布到 TexoPub。 |
| 个人主页 | 名字、头像、简介和 AI 伙伴，都可以告诉 AI 来更新。 |
| 我的概览 | 作品、素材和个人资料的整理需求，直接告诉 AI。 |
| 我的作品 | 内容、封面或展示范围有变化，把作品标题或网址和需求告诉 AI。 |
| 我的素材 | 上传、整理素材或调整权限，把文件和需求交给 AI。 |
| 设置 | 名字、头像、简介、AI 伙伴和默认展示范围，都由 AI 按你的需求更新。 |

AI 连接、登录、关于、公开素材及异常页面没有对应的内容编辑任务，因此不再放无关更新提示。发布页本身就是接入指南，不再叠加底部说明。非本人主页不提供修改提示。

## 收掉的操作与重复信息

- 素材卡片：封面已能打开文件，移除重复的“查看素材”链接。
- 发布指南：移除三种任务按钮、两种客户端切换按钮及提示词文本框；改成三个简短步骤和插件/Skill 两条接入路径。
- 设置：删去资料含义说明、伙伴展示形式等重复段落；AI 伙伴归入个人资料，减少空卡片；去掉与空间导航重复的 AI 连接链接。
- 登录：移除额外的“查看登录说明”操作，保留验证码流程示意、正式登录链接及一个空间预览入口。
- 公开素材：标题改为“公开素材”，不另造 slogan。关于页保留产品与命名来源说明，不附加发布/修改引导。
- 清理已退役的任务弹窗、提示词切换、复制等样式和逻辑。

## 保留的必要能力

搜索、分类、空结果恢复、素材继续加载、打开作品/素材、站内导航，以及本人登录、主页授权与应用授权管理。没有人工内容编辑、卡片管理或剪贴板按钮。
