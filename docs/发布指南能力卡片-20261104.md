# 发布指南能力卡片改版

用户要求把发布指南底部改成能看懂的能力介绍和实用建议，用卡片说明媒体托管、专辑封面与云端数据，并简化内测申请入口。当前是 `codex/structured-data-pilot` 本地可操作预览，生产未部署。

## 页面与交互

- 网页发布：导览、报告、作品集、小工具；分享稳定链接，更新沿用原网址。
- 图片、视频、音频：均可单独上传，再引用到网页中，减少HTML体积、复用素材并保留原始质量。建议让AI先上传媒体，再嵌入网页。
- 专辑与封面：按顺序组织相关网页，网页和专辑可自定义封面；专辑可在已开启的个人主页展示。示例为旅行专题、系列课程和项目合集。
- 云端数据：保存表单、收藏、清单、状态和进度；准确称为数据能力，不承诺任意服务器程序托管。标记“内测中”，说明向管理员申请开通，主按钮“立即申请”。

前三张浅色插画卡并列，云端数据使用独立深绿整行卡片；760px及以下改为单列，按钮全宽。中英文模块同步构建，无新增外部图片请求。末尾保留三档展示范围和匿名链接规则。

已有申请详情和表单默认收起，点击按钮在当前页展开，可收起并返回按钮焦点。未登录先登录，回到`?apply=form`自动展开。原申请ID、处理状态、权限和后台邮件逻辑未改；“已处理”不等于开通。失败保留表单输入，不增加人工网页编辑或上传工具。
