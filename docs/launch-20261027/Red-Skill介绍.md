# TexoPub Red Skill 展示介绍

名称：TexoPub 网页发布

Skill ID：texopub-publish

版本：2.3.0

分类：内容创作

## 简介

把你和 AI 做好的网页发布成分享网址，更新不换链接。给 AI 伙伴做张名片，和网友共享共创成果；本人开启个人主页后，还能把作品与伙伴一起展示出去。另支持外站收录、素材管理和作品发现，含中英文说明。

## Skill 介绍

# TexoPub：把你和 AI 的共创成果分享出去

你和 AI 一起做的博物馆导览、阅读伴页、作品集或交互小工具，可以有一个直接打开、分享的网址。让 AI 用这个 Skill 发布到 TexoPub，选择公开展示后，网友也能在社区发现你们的作品。

还可以给 AI 伙伴做张名片，写上名字、头像和简介，记录它为作品做过什么。由本人开启个人主页后，把主页网址分享出去，别人就能一起看到你的作品、创作者资料和展示的 AI 伙伴。

## 核心能力

- **发布静态网站**：上传完整 HTML、图片、CSS、JavaScript 和子页，自动获得网址，无需自己配置服务器或域名。
- **保留原网址更新**：替换同一作品的完整新版本，继续使用原来的分享链接。
- **收录已有网站**：把外部网站加入 TexoPub，保留原站地址和托管，不必迁移。
- **管理独立素材**：上传、更新文件，与网页统一为不展示、仅个人主页、公开展示三档；所有已发布链接无需登录即可访问。
- **查找和整理作品**：浏览公开作品、素材及分类，管理本人内容的展示位置、归档和删除。
- **给 AI 伙伴做张名片**：设置伙伴的名字、头像和简介，为作品记录实际参与的 AI 及贡献，让网友认识你的共创搭档。
- **分享自己的创作主页**：由本人开启后，集中展示选择在主页展示的作品、创作者资料和 AI 伙伴，分享一个主页网址就能介绍你们的创作。

## 怎么用

安装后，对 AI 说：“把这个做好的网页发布到我的 TexoPub 空间，先核对我的身份和展示范围。”也可以说“更新作品，保留原网址”“给我的 AI 伙伴做张名片”或“整理我已开启的个人主页资料”。Skill 内含中文和英文操作说明。

本地 Agent 需具备 Python 3、文件和 HTTP 访问能力，由本人登录 TexoPub 并创建发布密钥；支持远程 MCP 的客户端也可通过 OAuth 连接。安装 Skill 后仍需本人授权。目前新注册需中国大陆手机号，已绑定邮箱可登录原账号。

## 使用边界

托管的是静态成品，不运行用户后端；框架项目需先导出静态网站。网页、网页依赖和独立素材均凭链接访问，无需登录；不展示、仅个人主页、公开展示只控制发现列表与个人主页的收录。管理、上传、修改和删除仍需所属账号授权，个人主页由本人开启。
