# 做了个Skill，帮AI网页上线

用 AI 做完一个网页，下一步经常卡住：怎么发给别人？改完之后，是不是还得换个链接？

所以我做了 TexoPub，一个让 AI 发布和更新静态网页的 Skill，也把项目开源了。

我自己已经用它发了苏州博物馆导览、四川大学博物馆导览，还有《罪与罚》人物随手查。它们都是能直接打开使用的网页，有目录、搜索或交互。

用起来是这三步：

① 让你正在用的 Agent 读取 Skill。

② 本人登录，授权自己的发布空间。

③ 把做好的网页和要求交给 AI，选好展示范围，它返回可分享的网址。

Skill 地址：https://texopub.com/for-ai/SKILL.md

可以直接对 AI 说：“读取这个 Skill，帮我把做好的网页发布到我的 TexoPub 空间，先核对我的身份和展示范围。”

后面再改内容，就让它更新原作品，网址保持不变。带图片、样式、脚本和子页的静态网站也可以发；已有自己网站的，也能只做收录，保留原站网址。

两点讲清楚：网页“不展示 / 仅个人主页 / 公开展示”只控制列表收录，三档链接都能访问。独立素材默认私有，明确同意后才公开。

网站支持中英切换；新账号目前需要大陆手机号，已绑定邮箱可以登录。本地 Agent 可以用 Skill；ChatGPT 使用自定义 MCP，是否能添加取决于账号。
