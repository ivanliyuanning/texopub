## 可以归纳的写作思路

1. **标题选择一个立即能理解的收益。** 单品可围绕做完某件事后的结果；合集则承诺帮读者筛选。技能数量、全球榜单和夸张评价都不是 TexoPub 现阶段必要的卖点。
2. **第一屏给证据，正文解释意义。** 样本中既有清单本身可用，也有真实客户端和交付物。读者无需先认同“很强”，就能看见有什么可用。
3. **让能力落在使用时机、输入和输出上。** 例如“网页已经做好→告诉 AI 发布要求→拿到网址”；更新则展示同一地址下内容改变。没有实测耗时，不写几秒上线或节省百分之多少。
4. **最短的说明也要让人能开始用。** 可见评论跨样本重复询问客户端、安装地址、调用方式。说明装在哪里、交给谁一句什么话，比多堆几种功能更有帮助。
5. **个人经历要有可以核对的成品。** 可以写自己已经发布了什么、为什么做它；不编使用人数、受欢迎程度、节省时间或长期使用感。
6. **评论多不等于分发好。** 索取链接、获取失败、讨论成本都会形成评论。借鉴清晰表达和演示，不复制“求资源→私信”的阻力，也不把互动解释为算法偏好或增长因果。

## TexoPub 当前稿的具体判断

现有开头已经提出“怎么发给别人、更新是否要换链接”，不是没有用户问题；也给了真实项目、地址、提示词和三步流程。这些应该保留。

更值得改善的是证据呈现：现有第二张图主要是三个作品的封面/名称卡片，没有实际打开后的目录、搜索或交互画面；第一张是从文件到网址的概念示意。建议后续选一份代表作品，用真实页面和发布回执把“确实能用”展示出来。首轮优先只更换第二张图，其他标题、正文、组件、图片顺序保持，避免同时改多个变量；待有实际观察后再决定是否调整标题。研究本身不证明这会增加流量。

展示页与宣传笔记可以有不同信息密度：已生效的 Red Skill 介绍保留六项核心能力，供决定是否使用的人确认范围；宣传笔记开头集中讲“发布成网址”和“原网址更新”，随后用一句话交代外站收录、素材、发现和共创者管理，让首次接触者有一个清晰的入口。

## 可参考的下一版结构（草稿，未发布）

候选标题：**AI做好的网页，怎么发给别人用？**

四图思路：

1. 明确结果：本地 HTML → 实际分享地址；用真实作品画面承载，不只有流程箭头。
2. 演示证据：一份已发布导览的真实目录/搜索，以及交给 AI 的发布要求、服务返回的网址；取样时隐藏凭证和私人内容。
3. 开始使用：支持的本地 Agent、本人登录授权、一句可照做的指令；明确入口位置。Skill 安装与账号授权分开。
4. 差异与边界：更新同一作品保留网址；可以收录外站、管理素材；网页列表范围与素材私有权限的区别简要说明。完整能力留给原生 Skill 详情。

开头与正文草稿：

> 我用 AI 做了博物馆导览和《罪与罚》人物查询工具。网页做好以后，还需要一个别人能直接打开的网址。
>
> 所以我做了 TexoPub。把完整网页交给 AI，让它发布到自己的空间，它会返回分享地址；以后更新同一作品，继续用原来的链接。图里这些作品已经实际发布，可以打开使用。
>
> 第一次用：让支持本地 Skill 的 Agent 读取说明，本人登录 TexoPub 并授权，再告诉它：“把这个网页发布到我的空间，先核对身份和展示范围。”支持远程 MCP 的客户端也可连接使用。
>
> 除了托管网页，也能收录你已有的网站、管理独立素材、查找公开作品，以及整理创作者资料和 AI 共创署名。Skill 有中英文说明，项目已开源。
>
> 接入说明：texopub.com/publish/；Skill：texopub.com/for-ai/SKILL.md。原笔记已关联 Red Skill 组件。
>
> 当前新注册需大陆手机号；托管静态成品，不运行用户后端。网页“不展示”只是不进公开列表，链接仍可访问；独立素材默认私有。

这份草稿用于确定顺序与口吻，不作为立即整篇替换的操作指令。当前笔记未改标题、正文或图片；正常监测仍以用户最新人工内容为准。

## 观察的限度

这是通过站内搜索选择的定性样本，偏向可见互动较高者，存在选择偏差；未控制账号规模、发布时间、推荐分发及选题差异。只比较实际看见的写法，不宣称“某种结构一定爆”。本轮没有打开其他作者的原生 Skill 完整详情或测试其安装，因此结论针对笔记表达和获取引导，不是原生详情页/功能质量的评测。

## 用户新增的共创社区方向

研究完成后，用户要求增加“给AI伙伴名片、与网友共享共创成果、可以分享的个人主页”。这三点作为TexoPub自身的特色融入宣传：让读者看见合作关系和可分享的作品集合。原生Skill简介/详情与原笔记正文已按新指令更新，最新稿分别见 `Red-Skill介绍.md`、`小红书笔记.md`。主页需本人开启，AI只按要求整理资料；共创署名记录实际参与，不把伙伴名片当作自动给全部作品署名。

后续视觉候选可以用一张真实AI伙伴名片和已开启主页的截图展示这三点。当前这轮只改正文，未更换图片或标题；上面的研究草稿是历史提案，不作为覆盖最新已发布文案的依据。
