# 外部 AI 发布服务：第一版建议

日期：2026-10-22。状态：方案，尚未实现或开通云资源。本次用户询问下一步如何让其他人的 AI 上传网页、独立素材并自动加入导航。

## 当前起点

已核对：现有发布器在本机读取 `library.json`、全量生成内容，并通过 Wrangler 发布两个 Pages 项目。已有分类校验、专属图标、独立素材、去重与版本冲突保护；没有外部发布 API。`cloudflare.json` 仍记录 `r2_enabled=false`，这只是本机保存的配置，不代表本轮已实时查询账户订阅状态。

## 推荐范围

先做邀请制 API，通过一个真正不依赖本站 Mac 的外部 AI 完成端到端验证。第一版包含发布者身份、独立素材上传、网页发布/更新、自动导航、可撤销凭证、基本额度及管理下架。公开注册、推荐排序、社交互动与语义搜索留待后续。

发布者第一次取得专属发布凭证，在自己的 AI 工具里配置；把站点的 AI 发布说明链接交给 AI，即可选择分类、制作图标、准备文件并发布。服务只托管静态 HTML/CSS/JS 与素材，不执行上传者的服务端代码。

## 服务边界与数据

- Pages：首页、分类浏览和发布说明沿用现有站点；接入云端公开目录，新增作品无需重新部署整个首页。
- Worker：提供身份验证、上传会话、发布提交、目录查询与管理 API。
- R2：保存内容包、独立图片音视频文档以及图标，上传对象与公开发布对象分开管理；大文件直接上传，不把整包视频塞进一次 API 请求。
- D1：保存发布者、撤销状态、作品归属、版本、文件清单、分类/标签/形式、待上传与已发布状态。
- 云端目录成为多人发布的权威数据；本机 CLI 逐步成为该 API 的另一个客户端。导入已有苏博条目并保留其 URL；切换后阻止旧本机全量发布覆盖云端目录。

## 一次发布的流程

1. AI 获取分类和能力说明，准备标题、摘要、二级分类 ID、内容形式、标签、专属图标和文件清单；客户端处理本地引用与素材提取。
2. 带所属发布者凭证创建上传会话，服务校验权限、额度与元数据，分配唯一作品ID/版本和受限对象路径。
3. 返回需要上传的文件及短期上传地址；AI上传缺少的素材，重试沿用同一个会话及幂等键，避免重复作品。
4. AI提交完成请求。服务器核对文件是否齐全、大小、类型、引用与图标；不能只信客户端声称已经上传完成。
5. 校验成功后才切换作品的公开版本及目录状态，返回公开URL。文件上传失败或校验失败的草稿不出现在导航。目录缓存应有明确的短时刷新机制。
6. 以后更新同作品保留URL，仅发布者本人或管理员可以改动；保留先前版本用于回退。

R2预签名URL在有效期内可能重复使用，因此直传先落暂存路径，完成校验后发布不可变版本；不能把仍可写的暂存对象直接当作已发布版本。原件与哈希验证、并发更新冲突和清理未完成上传都要在实现中处理。

## AI 接入形式

先提供公开 `/for-ai` 说明、OpenAPI定义、可下载的通用发布 Skill，以及远程客户端/CLI。HTTP API为基础；能读取本地文件、发HTTP请求并配置凭证的代理可直接使用。不同AI客户端能力不同，不声称所有聊天窗口都能直接上传。后续可在同一API上增加MCP，不另做一套数据与发布逻辑。

建议接口（尚未实现）：

- `GET /v1/categories`：分类与内容形式。
- `POST /v1/uploads`：创建会话、校验元数据、分配上传目标。
- `POST /v1/uploads/{id}/commit`：核对文件并发布，支持幂等重试。
- `GET /v1/works`、`GET /v1/works/{id}`：公开目录与作品元数据。
- `POST /v1/works/{id}/versions`：仅所属发布者可创建新版本。
- `POST /v1/assets/uploads`：独立素材会话，完成后可用于作品或素材目录。

## 多人发布的必要约束

凭证按发布者隔离且可撤销；平台内部Cloudflare凭据仅用于服务部署和签名。上传内容在独立来源承载，不能与目录/登录/管理界面共用安全来源；上线前选择按作品隔离的域名方案，或明确沙箱及跨作品存储的限制。标题/摘要/标签按纯文本输出，不执行作者传入的HTML。

每个发布者有明确的单文件、总存储与频率额度。管理员可撤销发布资格、下架作品，提供归属、来源、版权/分享许可与举报入口。邀请制成员可在自动检查通过后自动收录；未来开放注册时再定义审核和索引资格。

## 验收标准

在本站Mac不运行发布器时，另一个发布者的AI能依据公开说明发布一份新HTML和图片：自动归入正确分类、具备自己的favicon、独立素材可访问、导航自动出现；重试无重复条目；更新保留URL；另一发布者无法覆盖；失败草稿不进入导航。苏博保持可访问。
