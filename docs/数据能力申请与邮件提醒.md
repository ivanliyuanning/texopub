# 数据能力申请与邮件提醒

用户2026-11-04要求在发布指南增加申请入口，保存全部申请，并在有申请时提醒；随后明确选择邮件提醒。此功能与通用数据试用在同一开发分支，当前为完整隔离预览，生产尚未迁移、部署或开始真实发信。

## 使用流程

- 发布指南`/publish/`及`/for-ai/`新增数据能力申请区域。未登录先登录；已登录填写用途、选填的HTTPS网页和联系邮箱。信息关联本人账号，申请者仅能查看自己的记录，管理员能查看全部。
- 每个账号保留一份申请。重复或并发提交返回同一份已存记录，不生成重复通知。当前申请内容提交后不提供在线改写/再次申请；页面明确展示这项限制，并保留原始用途和联系方式。
- 申请提交以数据库保存成功为准。申请和提醒任务在同一次D1写入中落库；发送邮件在后台办理，发信失败不撤销申请。页面显示申请编号和处理状态，信息不进入作品目录，与listing无关。
- 管理员在`/api/v1/data-applications/admin/`按待处理/已处理/全部筛选、分页，记录处理备注，标记处理或恢复待处理，并查看提醒状态/重试未送出的提醒。原申请和处理记录保留。标记处理不会自动加入数据能力白名单，不直接开通权限。
- 申请人和普通AI发布密钥不能查看管理员队列。管理页面需要本人主站登录；状态修改和手动重试要求15分钟内验证、同源Origin与CSRF标记。不向申请人返回管理员邮箱或处理备注。

## 邮件提醒

接收者从运行时`APPLICATION_ADMIN_PUBLISHER`所指定的管理员账号，读取已验证绑定的备用邮箱，不接受申请者指定接收地址。用户真实账号已只读核实存在绑定的Gmail邮箱；公开源码和此文档不保存账号ID或完整邮箱，部署参数在被Git忽略的`.secrets/applications-runtime.json`。

沿用现有阿里云DirectMail发信通道，不新增服务器或购买套餐。邮件仅含新申请数量、申请编号和登录管理链接，不附用途正文、申请人的联系邮箱或手机号。用户选择的是邮件，不创建Codex轮询提醒或其他通知渠道。

新申请提交后通过Workers后台任务尝试提醒；`*/5 * * * *`维护Cron负责未成功任务的重试。并发发送使用120秒租约防止重复处理同一批；每批最多合并20份。成功收到发信服务确认后才标记完成，这表示发信服务接受，不等于已证明收件箱送达。网络响应丢失等情况下重试仍可能造成重复提醒，不能宣称邮件严格只投递一次。

失败将保存尝试次数、下次时间和固定错误分类，不记录云密钥、验证码或供应商原始错误。重试从5分钟开始指数退避，最长6小时；服务未配置时同样保留任务等待重试。每UTC日最多100次发信尝试，达到后保留任务至次日；主站登录验证码邮件不占这个功能的日计数。后台维护不依赖本地Codex在线。

数据库限制：每日最多50份新申请、累计2000份；申请/处理记录按UTF-8字节加元数据预留计额，总预算16MiB。约束通过D1事务/触发器原子执行，达到上限返回明确错误，不会先显示提交成功再丢弃记录。无匿名提交，不自动删除已有申请，不为发信成功清除申请记录。实际物理D1、其他平台流量和邮件供应商费用仍按原服务规则监控。

## 接口与迁移

申请服务使用原主库，`service/migrations/0011_data_applications.sql`添加独立申请、处理日志、邮件待办及预算/租约表，不要求申请者已经开通DATA_DB，也不占其业务数据库额度。

| 接口 | 权限与用途 |
| --- | --- |
| GET `/api/v1/data-applications/me` | 本人登录；当前申请、是否开通与管理员入口标志 |
| POST `/api/v1/data-applications` | 本人登录+CSRF；用途必填，网页和联系邮箱选填 |
| GET `/api/v1/data-applications/admin/` | 管理员登录；管理页面，未登录转登录页 |
| GET `/api/v1/data-applications/admin` | 管理员；status筛选、before游标，每页20条 |
| POST `…/admin/{id}/status` | 管理员近期验证；expected_revision、pending/handled、note，版本冲突拒绝 |
| POST `…/admin/{id}/retry` | 管理员近期验证；重新安排未确认发送的提醒，不重复重发已确认任务 |

非管理员无法通过猜ID、发布密钥或跨站请求读取申请。服务器正文限8KiB、用途UTF-8最多4000字节且至少5字符，网页2048字节、邮箱254字节；只保存文本，不抓取所填网址。管理员页面及申请状态显示均转义/使用textContent，不执行申请人内容。中英文发布指南与账号隐私说明已同步。

- 管理入口：http://localhost:8792/preview/login?as=author&next=%2Fapi%2Fv1%2Fdata-applications%2Fadmin%2F

浏览器控制接口曾超时，改用原生Chrome窗口完成真实页面提交、申请确认、管理员回读、模拟邮件状态和标记处理后仍保留记录的验收。6项新增服务检查包含CSRF/账号隔离、重复并发提交、并发处理版本冲突、发送失败重试、配额事务回滚、并发发信租约及日上限。全套Node 121项、Python24项通过。

证据集中于`evidence/data-applications-20261104/`，包含浏览器截图、独立回读、测试及迁移兼容记录。预览中的“邮件已提交发送服务”来自明确标注的模拟服务，不能当作真实Gmail已收件。
