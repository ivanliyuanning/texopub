## 完成标准与已完成事项

- 独立DATA_DB schema与原库兼容迁移；主库保留作品/账号，业务记录独立存储。新账号文件默认5GiB；数据50MiB/账号、25MiB/作品，3应用，记录/字段/索引/字节/日请求及操作预算均限制。数据库事务保证容量与数量并发限制；额外测试确认并发超额写入只有一个成功。
- owner/public_read/user_private三模式；访客仅能读写自己的私有集合记录，作者及其明确授权AI可管理全部，授权页明示。旧密钥/OAuth不扩权，数据独立scope和应用范围。本人浏览器创建数据密钥，短期会话绑定grant，支持过期与撤销。
- 保留作品opaque iframe沙箱，平台外层真实点击打开受信窗口；SDK与MessageChannel桥接，网页收不到cookie、管理密钥或grant。Chrome实测已完成连接、新增、修改、历史、恢复、刷新后重读，CLI写入后网页读取同一条记录。
- 记录CRUD、受索引约束的等值查询/投影/分页，revision、24小时幂等、5版/7天历史、恢复、导出、清空历史、分批删除集合/应用、额度与状态管理。普通更新保留绑定，配置随新版网页发布激活，旧网页版本不能访问当前数据。
- asset_ref与记录/历史共同pin资源；跨库租约、保守pin与持久清理任务防止误删。删除网页联动清理业务数据、历史、授权和引用。定时维护代码及部署说明齐备，生产Cron尚未配置。
